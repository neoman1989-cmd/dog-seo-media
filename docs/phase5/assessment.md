# Phase 5：収益性の再評価

調査日2026-10-12 JST。main 9c2d0b4（Phase 4のPR #4）から作業。既存ペットサイト・テーマ・3記事・商品台帳・広告設定を変更しない。

提案は **ペットを維持し、小規模事業者向けWordPress・Web運用を非公開で並行検証する**。全面転換・新ドメイン取得・公開はしない。現時点で「利益5万円に到達する確率が高い」と統計的に確定できるジャンルはない。提案は公開案件の金額と成果地点、既存検証資産、制作と運用の制約による暫定優先順位である。

## ペットを優先調査した結果

- FPC公式でペット保険の商品・代理店募集を確認。ただし保険商品や代理店募集はSEOアフィリエイト案件の存在を意味しない。2,000円以上の報酬・成果地点は未確認。
- Furbo公式で製品・消費者契約を確認。製品価格・サブスク料金を紹介者報酬と取り違えない。直接アフィリエイト案件/単価/成果地点は未確認。
- A8の公開ペット/キャンペーン候補URLは404。犬の留守番、ペットシッター、ペットフード定期購入の具体的な稼働案件・報酬は確認できなかった。

公開調査で確認できなかったことを「ペット高単価案件は存在しない」と解釈しない。ASP登録・ログイン・申請は行わない。本調査でペットの固定2,000円以上を収益モデルへ入れられる証拠は得られなかった。既存記事の維持を継続し、増産を止める。

## 予算

今回の追加支払い・契約・ASP登録・外部アカウント・公開は0件。既存環境で資料調査、試算、企画のみ。初期30,000円・月額3,000円は全サイト合計の上限で、ジャンルごとの別枠ではない。

並行検証はまず追加ドメイン・ホスト・SaaSアカウントなし。将来の新ドメインや検証ライセンス、監修費の確定額は未確認。既存請求も含めた総額が確認できるまで投資しない。有料順位API、ライフタイム報酬の見込み、自己申込報酬を計画収入にしない。自分の労働時間は金銭予算と別に記録し、週4〜6時間を仮の上限として見直す。
