# 最優先候補のキーワード20件と記事5企画

対象は小規模事業者向けWordPress・Web運用。data/phase5/keywords.jsonに20語、article-plans.jsonに5企画を保存。新しい記事・サイト・ブランドを実際に公開したものではない。検索量/順位/難度はnull。購買意欲と検索意図は語句に基づく編集仮説。

|企画|主要語群|独自資料の作り方|収益検証上の注意|
|---|---|---|---|
|12ヶ月総額と必要条件で選ぶ|個人事業主/小規模店舗/予算/更新料金/法人要件|公式見積り条件を揃えた表と計算式|初回契約需要がある読者か、本人が対象プランを紹介できるか|
|移行・事業影響チェック|引っ越し/ドメイン/メール/DNS/失敗時復旧|既存のローカルDockerで再現可能な手順|既存顧客や乗換が成果対象と仮定しない|
|バックアップと復元|保存先/更新前/復元確認/ローカルステージング|既存環境の復元ログと画像を使う企画|新しい契約が不要なら買わせない|
|問い合わせメールの切分け|店舗メール未達/制限/フォーム個人情報|架空データとローカルでの切分け|顧客情報や新アカウントを作らず、現在の設定で解決する道を残す|
|事業サイト公開・引継ぎ|HTTPS/公開チェック/権限/運用引継ぎ|このrepoの下書き・公開停止・権限検証|オーナー許可と予算が前提。記事制作を公開許可と混同しない|

企画は全て、普通の公式リンクでも読者が条件を確認できる構造。ASP承認後の実URL切替は既存の承認・期限・URLハッシュ設計に従う。ホスト比較の順位付け、未契約ホストの速度テスト、未使用SaaSのレビュー、実店舗成功事例を創作しない。

「レンタルサーバーおすすめ」のような広い商業語だけを狙わず、具体的な事業運用の問題と選択条件に絞る。これが実SERPで差別化になるかは未確認。20語すべてが十分な流入を持つと仮定して収益モデルへ入れていない。
