# 利益5万円までの仮説と90日判断

最有力候補は小規模事業者のWordPress・Web運用。公開掲載の標準5,000円を本人に適用でき、1件の成果が適格と認められる場合、月11件で売上55,000円、月額費用3,000円なら営業利益52,000円。10万円には月21件。**本人提携・実成約・需要は未確認なので到達確率や実績ではない**。

中間仮説は月約22,084PV、8%送客、送客後1%の対象イベント到達、60%の条件成立。これは期待値計算であり11件を保証しない。単純な「高単価なら低PVで儲かる」結論を避け、保守70,667PVも需要の実測と照らす。

## 0〜14日：証拠と仮説を揃える

公開の固定単価・成果地点・条件を保存し、未知単価を除外。既存ペットを維持、記事の増産はしない。新ジャンルの20キーワード・5企画は非公開の企画だけ。追加支払いなし。

## 15〜30日：参入の前提を確かめる

通常ブラウザで20語の日本Googleを複数日観測し、広告/有機/動画を分ける。公式・大手比較・実務手順の不足を具体的に記録。検索ボリュームが取れなければnullのまま。需要と必要PVの両立が説明できない場合は全面転換しない。

独自のローカル検証を1件設計し、制作/仕様更新に掛かる時間を記録する。週4〜6時間は仮の上限で、無料環境でも労働コストはゼロではない。本人ASP条件を確認するには今回禁止されている登録等が必要になる場合がある。そのときは次段階の別許可がない限り進めず、保留とする。

## 31〜60日：許可後のみ小規模検証

ここからは別途オーナー許可・確定費用・本人提携・公開許可が前提。現在の指示で実行しない。

許可された場合も5企画以内で開始し、記事量より適格送客を検証する。通常公式リンクと広告成果は区別。送客・申込・条件成立・承認・実費を追跡する。未計測を0成果と呼ばない。本人が使える案件を可能なら2社確認し、1社依存リスクを記録する。自己申込・架空契約で成果を作らない。

## 61〜90日：保留・継続・案件見直し

- 全サイトの初期30,000円/月額3,000円を超える追加投資は停止。
- 公開後45日未満または追跡できた送客300クリック未満ならデータ不足。90日だから失敗としない。
- 条件と追跡が正しく、上記母数でも承認成果0なら、対象読者・成果地点・案件を見直し、追加記事を止める。サイトを削除しない。
- 承認成果が出たら実収益/PVを計算し、利益5万円に必要なPVを再計算。実需要・流入・制作負担と両立する場合だけ限定継続。成果が1件出ただけで確率が高いと断定しない。
- 依然として本人条件/SEO需要/追跡が不明なら非公開調査へ戻す。全面転換は保留。

45日/300クリックは今回の運用判断しきい値で、統計的な成功保証やGoogleの推奨値ではない。新サイトはSEOの観測に90日以上掛かることもあり、期限による自動的な勝敗判定は行わない。

機械判定はseo_media.phase5_decision.assess。現状のartifacts/phase5/decision.jsonはhold（全体実費未確認）。追加支払いなしの非公開調査だけを提案する。費用確認後も公開許可が無ければoffline_parallel_only。判断は読み取り専用で、課金・登録・公開・既存サイト変更を一切実行しない。
