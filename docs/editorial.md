# 編集・自動化運用

現在の自動化範囲: ブリーフ入力 → 記事生成 → 台帳・出典・品質・重複検査 → 記事JSON → 人による確認・ハッシュ承認 → 独立した下書き投稿。Actionsはモック生成artifactまで。

台帳の公式URLは実在・仕様・価格・確認日を人が確認。機械検査はHTTPS、本文参照、商品ID、名前、30日以内の確認日、最低文字数、比較表と出典、類似本文、危険なHTMLを検査する。価格の意味的照合、盗用検知、外部Web全体との重複判定、専門家の安全評価を代替しない。

編集チェック: 読者の疑問に答えるか／公式情報に一致するか／広告を明示したか／体験を創作していないか／比較条件は公平か／健康の断定がないか／著者・更新日・出典はあるか／リンク先の契約・解約条件は適切か。全項目を人が確認してWordPressで公開する。

毎週: Search Consoleの検索語、表示回数、クリック数、CTR、平均掲載順位を確認。8〜20位の記事は意図・見出し・内部リンクを見直す。商品情報は30日以内に確認、停止した案件リンクは削除。月次で承認売上、否認率、API費、サーバー費、営業利益を集計する。

Search Console取得、順位追跡、自動リライト、WordPress上の更新履歴、承認状態管理は今後の実装。リライトは元記事を保持して差分レビューし、自動公開しない。
