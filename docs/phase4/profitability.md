# 収益性を先に確認する

調査日2026-10-12。現時点でASP承認、実売上、実PVの確認がないため、収益性は実証されていない。記事本数を増やす決定は保留する。

利益 = PV × 公式/広告リンククリック率 × 送客後成約率 × 承認率 × 承認報酬単価 − 月間外部費用。

ここでクリック率はサイト全体PVに対する送客率、成約率は送客後の購入率。両者を混同しない。注文単価ではなく成果報酬を使う。商品ジャンル、税・送料の計算対象、上限、キャンセルを考慮して実報酬へ置換する。利益は税引前、オーナーの労働費・機会費用を含まない。初期支出は別枠で管理する。

## 続行判断

1. オーナーがASPで対象案件・商品、承認報酬、成果地点、否認条件、広告利用条件を確認する。提携申請はオーナー許可後のみ。
2. 既存3記事に適合する案件を選ぶ。高報酬だけで犬の安全性や品質を保証しない。
3. Googleの実SERPを確認し、検索意図に答えられる余地があるか判断する。順位・検索量を仮説で埋めない。
4. 公開許可後、既存3記事で4〜8週間の小規模検証。PV・送客・承認成果・実費を記録する。母数が少なければ結論を出さない。
5. 収益/送客・収益/PVを算出し、目標に必要な規模を再計算。報酬未確認、在庫なし、送客なしなら記事増産より案件・記事意図を見直す。
