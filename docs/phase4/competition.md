# 競合調査の結果と代替手段

日本Googleで「ペットカメラ 月額なし」「犬 留守番 カメラ 選び方」「ペットカメラ 録画 SDカード」を再調査。hl=ja、gl=jp。HTTP取得は200だが本文はJavaScript誘導のみ。過去のChromium取得はERR_CERT_AUTHORITY_INVALID。

OSの信頼CAでPythonのTLSは検証できる一方、ChromiumのNSSとOSで環境提供CAの信頼設定に差が見られた。ホームNSSへの書込み権限は取得できず未変更。証明書検証を無効化したり、別経路でホームを書き換えたりしていない。

合法的な代替としてBingの公開検索を実行。日本語・日本地域指定も試したが、コロナウイルス・百科事典など対象語句と無関係な結果が含まれ、比較可能な競合として採用しなかった。Bingの結果をGoogle順位と表示しない。証跡data/phase4/competition.json。検索ボリューム・Google順位・競争難易度は未取得。

## オーナーの通常ブラウザでの無料調査

1. ログアウト状態の日本Googleで上記3語と「ペットカメラ 犬 吠える 通知」「ペットカメラ クラウド 月額」を検索。地域・端末・日時を記録する。
2. 広告/ショッピング/動画と通常の有機結果を分け、各上位ページを実際に読む。検索結果は個人・地域・時刻で変わるため固定順位としない。
3. メーカー、EC、比較メディア、実機レビューを分類し、料金条件・ハードウェア版・出典・在庫・契約更新の記載を確認する。
4. data/phase4/manual-google-audit.csvへ観測を入力。URL、観測順、スクリーンショット等の証跡と、具体的に不足する回答を記録する。空欄を推測で埋めない。
5. 需要や難易度の結論は複数語・複数日の観測後に編集者が判断する。有料順位API・自動CAPTCHA回避・検索規約に反する大量取得は使わない。

## 記事の改善仮説

実競合に勝っているとは主張しない。現行3記事には、公式引用・確認日・ハードウェア版、Tapo/eufy/Furboの横断比較、割引本体価格と継続契約の区別、未確認料金の表示、在庫確認、非購入の選択を残した公式リンク導線を追加した。これらが差別化になるかは実SERPと送客実績で検証する。実機レビューやランキングは作らない。
