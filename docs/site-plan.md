# サイト・事業設計

対象は犬を留守番させる日本の飼い主。サイト名は仮称「犬の留守番ガイド」。無理な長時間留守番を推奨せず、犬に合った環境づくりを優先する。

## 情報構造

ホーム → 留守番の基礎 / ペットカメラ / 自動給餌器 / 関連サービス。各カテゴリは選び方の柱記事から比較・個別レビュー・設定方法・費用解説へ内部リンクする。レビューは実体験または公式資料のどちらに基づくか明記。著者紹介・編集方針・広告表示・訂正窓口を整備する。

最初の候補: 犬 留守番 カメラ 選び方、ペットカメラ 月額なし 比較、自動給餌器 犬 注意点、ペットシッター 留守番 費用。検索需要・競合は未調査の仮説で、検索ボリュームを創作しない。初月は柱記事3本と関連6本を人が検証して制作。商品ランキングは客観的比較条件が揃うまで作らない。
